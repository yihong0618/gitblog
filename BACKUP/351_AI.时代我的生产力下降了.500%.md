# [AI 时代我的生产力下降了 500%](https://github.com/yihong0618/gitblog/issues/351)

是的，题目没写错，准确说是今年开始，我的生产力下降了 500% 但具体内容大概跟题目的关系不大，想到哪里写到哪了吧。

- 今年开始，我失去了编程的快乐，准确说是去年 12 月的一天，Claude 出了4.6 codex 也更新了版本，在那之后，我再也没有过一次沉浸在一个 bug 一个功能不知不觉一下午过去，不断的尝试 google 开几十个标签，搜索过程中发现有趣的人有趣的博客，在 gdb 里看一个变量为什么变成了 4. 这种感觉再也没有了
- 也不会再为了一个点子开个新项目而快乐，解决了一个问题而兴奋了，上一次还能感觉到兴奋是过年的时候，我能在 telegram 里放一个烟花，现在呢？任何一个能叫出来名字的模型一个 /goal 就做到了
- 我应该是第一波被 AI slop ddos 的，当时不知道谁把我的项目放到了一个 issue Hunter 网站上，当时每天都有人不看项目给我提 PR 不过那时候的质量很低，基本一看就大概不对
- 现在任何一个人都能完全不看我们的任何一行代码，甚至都不知道项目是什么，来提一堆看起来质量非常高的 PR 我对这个生产力爆炸但却失去了原本意义的开源世界也逐渐的觉得沮丧
- 还有重写，不断的有人在用其它语言重写一个项目，对 LLM 来说确实很好用，也确实带来了速度的提升，但是是不是少了点什么？
- 我清楚的记得 ChatGPT 刚开放 api 那一天，我生产力爆棚一口气写了几个项目，有 xiaogpt, bbook, 等等，当时我觉得模型干扰甚至把 copilot 关掉，每天很多 issue pr 要处理我觉得很开心
- 去年不断的给其它项目提 patch 通过 bug 理解一个又一个项目我也觉得开心，解决了很多有趣的问题还会写博客分享，但现在我却失去了这种热情。
- 也不是抱怨，我依然敬佩 xuanwo yetone 空想家他们在 LLM 时代几十倍的生产力，也亲眼见到了Alma cc-switch 的诞生，但我在这个时代似乎在这里面无法再找到曾经的快乐，虽然也见证了这些项目的牛逼。
- 是的我觉得我寻找的更多的是一种 joy 一种过程中的感觉，而不是结果带来的 happy 于是今年我越来越多的做人与人之间连接的事情。包括帮助了很多朋友。
- 前几天和同事聊，他最快乐的时候也是 2024 年自己手写了非常多的算子，我说我大概是 2023 年作出 xiaogpt 的时候，我们都做了差不多的选择，从程序员的工作更多的去做人与人之间连接的工作了
- 当世界一切都在能一个 /goal 解决的时候，我们似乎不可避免的丢了中间心流中的过程
- 像今天我还记得 30 岁生日前的一天我去上班，脑子里还想着我写的一个项目的问题，怎么解决 cli 里面的翻页，当时我刚会写代码不久也刚转行不久，一下子就在走路的过程中想明白了什么是 stack 原来程序真的是数据结构加上算法，这种快乐大概这辈子不会有了。
- 又回到了时代永远会滚滚向前的讨论，我，我们，也很快会被新的快乐悲伤填满，但是这些大概再也回不去了。
- 手机打字真的挺累，北京地铁也真的长。
- 在一边打字一边想着今年没提什么 PR 倒是做了几个项目，都是给自己日常做的了。剩下的只有，我的生产力下降了500%
