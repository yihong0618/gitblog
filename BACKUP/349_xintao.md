# [xintao](https://github.com/yihong0618/gitblog/issues/349)

xintao 说过，他不想放弃 wordpress 因为一打开 wordpress 编辑器就文思泉涌。

我只用过一次 wordpress 于是我打来了 issue 试试自己能不能文思泉涌，我文思泉涌的时候一般手头都有一杯酒，当然，今天也有，这是第二瓶马上喝完。

xintao 还说过，不知道更新什么就写一些近况，我呢，好久没写近况了不如就写一写近况。
xintao 没说过他也不是这个风格用一条一条的 bullet 来写文章。

我不一样，我喜欢这种风格，能随时停止，AI 又写不出来，我很满意。

那么？下面是我的近况

- 换了新工作，加入了一家外企，具体不想多聊，但是有个忠告想给大家和未来的自己：千万别起一个英文名，如果非要起，别起一个大众的。我花了一个半月适应别人叫我 Joey 不发愣几秒之后，还是没法适应一个会议里有 2-3 个 Joey 带来的精神分裂的感觉。
- 重新玩了《baba is you》这是我玩过最棒的推箱子，尤其是在今天我想推荐给所有人，特别是程序员。LLM 可能让我们忘了编程沉浸式的感觉，但是这款游戏能让你找回来。第一次推荐还是在 piglei 的博客里--[游戏《蔚蓝山》教我的编程道理](https://www.piglei.com/articles/what-celeste-teaches-me-about-programming/) 6 年过去，我不再亲手一行一行的写程序，但是我又拿起了这两款游戏。
- 读了《七武器》，《缓步》《天龙八部》《镖人》和几个推理小说，推理小说是呼延云的，这货太自恋了，不做推荐。但是《缓步》里的《于洪》，我在飞机上读完了一遍，又读了一遍。想起了我死去的朋友。他就住在那里，他永远住在那里。
- 想起了 xintao 在结婚时邀请我去山东，我没去，当时有事，因为标题，此刻又想起，此刻他是爸爸了，我想起我刚爸爸的时候，守夜的时候，打通了《荒野之息》
- 见了认识好多年的朋友，跑步的朋友，当时他是我认识的最优秀的人。优秀当然不止体现在他北大毕业，年纪轻轻就是教授。优秀是体现在我 2 年前在人生遇到抉择的时候第一个想到了他。
- Good old days. 但是车轮滚滚向前。我没有其他办法。
- 同事都很好，我的老板更是非常好，老板的好体现这好像是我人生第二份工作老板比我干的多的多，也厉害的多的多。这两个多月学到了非常多的东西，只是稍微累了一点点。
- 当然最近几年最近几个月，我变了好多，认识了非常多非常多厉害的人。我天资愚钝，花了好久才知道自己擅长什么，也算幸运。希望能多幸运一点时间。
- 这两周太累了，等我忙完这段时间我要休息一下。
- 写到这，谢谢 xintao 祝你当爸爸快乐。
